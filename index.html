Welcome!

Welcome one and all to my website! This site was created as a way of becoming more comfortable with HTML and CSS. It's design was inspired by a bunch of different websites on neocities. Recent Going Ons

Lately I've been spending some time working on my YouTube channel, serge (I'm gonna rebrand at some point, but I dunno when). Specifically I've been working on a series dedicated to explaining how I like to configure my Arch Linux setup for various tasks that may be a bit niche for some people.

Arch Linux for Content Creators

I thought it would be helpful to document how I did these through YouTube, as my first thought when I want to learn how to do something is to look on YouTube. Unfortunately, aside from install guides, there aren't many channels dedicated specifically to Arch. Because I've committed to using Linux full time, and Arch is my distro of choice, I've had to spend a lot of time learning how to make programs that most people using Arch don't bother to use. Documenting my way of handling things like this, is good both for myself and for anyone else who might be encountering the same issues.
